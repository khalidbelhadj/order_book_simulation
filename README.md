# Order Book Simulation

This project implements a simple order book and matching engine in C++. It is designed for educational purposes, demonstrating the core concepts behind order matching systems used in financial markets.

## Usage

Build the project using the Makefile:

```sh
make
```

This will generate debug and release builds in the `build/debug` and `build/release` directories, respectively.


To run the debug build:

```sh
./build/debug/main
```

To run the release build:

```sh
./build/release/main
```
